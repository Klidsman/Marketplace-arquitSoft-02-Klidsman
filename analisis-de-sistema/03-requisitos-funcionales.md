| ID   | Requisito funcional |
|------|------------------------|
| RF01 | El sistema debe permitir buscar productos mediante criterios de búsqueda. |
| RF02 | El sistema debe permitir consultar la información y disponibilidad de los productos. |
| RF03 | El sistema debe permitir registrar y actualizar productos en la plataforma. |
| RF04 | El sistema debe permitir agregar, modificar y eliminar productos del carrito de compra. |
| RF05 | El sistema debe permitir generar un pedido a partir de los productos del carrito. |
| RF06 | El sistema debe permitir consultar los pedidos realizados y su estado. |
| RF07 | El sistema debe permitir registrar, actualizar y desactivar sellers de la plataforma. |
| RF08 | El sistema debe permitir consultar el detalle de un pedido realizado. |
| RF09 | El sistema debe permitir procesar el pago de un pedido a través de una pasarela de pago. |
| RF10 | El sistema debe permitir generar el comprobante de pago correspondiente a cada compra. |
| RF11 | El sistema debe permitir gestionar la información de entrega de los pedidos con el servicio de envío. |
| RF12 | El sistema debe permitir consultar la información de productos y stock proporcionada por el ERP. |
| RF13 | El sistema debe permitir el registro e inicio de sesión de clientes y sellers en la plataforma. |
| RF14 | El sistema debe permitir al administrador gestionar los usuarios registrados en la plataforma. |
| RF15 | El sistema debe permitir al administrador generar reportes generales de ventas y actividad. |
| RF16 | El sistema debe permitir a los sellers consultar la información relacionada con sus ventas. |
| RF17 | El sistema debe permitir enviar notificaciones a los clientes sobre el estado de sus pedidos. |
| RF18 | El sistema debe permitir enviar notificaciones a los sellers sobre nuevos pedidos recibidos. |
| RF19 | El sistema debe permitir aplicar filtros y ordenar los productos en los resultados de búsqueda. |
| RF20 | El sistema debe permitir al administrador gestionar categorías de productos dentro de la plataforma. |
